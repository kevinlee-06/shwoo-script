# 惜物 Script（僅支援 Firefox Android）

本倉庫包含一些用於提升惜物網使用體驗的油猴腳本：
- `info.user.js`
- `more.user.js`

## `info.user.js`
將惜物網的物品詳細資訊與出價紀錄整合在同一頁面，減少使用者移動滑鼠的需求。

<a href="https://github.com/kevinlee-06/shwoo-script/raw/refs/heads/main/info.user.js"><img src="https://user-images.githubusercontent.com/33416429/92813512-27f0bb80-f376-11ea-8562-ee2b3e416aec.png" style="width: 200px;"/></a>

## `more.user.js`
`more.user.js` 新增一個「顯示全部」按鈕，按下後會用 JS 狂摳惜物網以顯示更多內容，讓所有物品顯示在一個頁面。

<a href="https://github.com/kevinlee-06/shwoo-script/raw/refs/heads/main/more.user.js"><img src="https://user-images.githubusercontent.com/33416429/92813512-27f0bb80-f376-11ea-8562-ee2b3e416aec.png" style="width: 200px;"/></a>

## 使用說明
- 安裝 [Firefox](https://www.mozilla.org/en-US/firefox/new/) 和 [Tampermonkey](https://addons.mozilla.org/zh-TW/firefox/addon/tampermonkey/)
- 安裝腳本
- 前往[惜物網](https://shwoo.gov.taipei/shwoo/browse/browse00/advancedQuery)暴買一波
- 電腦必須用 [iframe](https://shwoo.superlily.dev) 或調窄視窗，不然篩選只剩地區有用



## 注意事項
- 這些腳本僅支援 Firefox 瀏覽器，Chrome 有 87 趴可能性會罷工。
- 使用這些腳本時，請遵守惜物網的使用規定。
- 電腦 Firefox 寬度須小於 768px，不然篩選只剩地區有用
